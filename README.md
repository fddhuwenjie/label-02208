# 医疗设备全周期管理平台

## How to Run

```bash
# 克隆项目后，在根目录执行
docker compose up --build -d

# 或使用旧版命令
docker-compose up --build -d

# 等待所有服务启动完成后访问
# 管理后台: http://localhost:8082
# 后端API: http://localhost:3000

# 查看日志
docker compose logs -f

# 停止服务
docker compose down
```

## Services

| 服务名称 | 端口 | 说明 |
|---------|------|------|
| frontend-admin | 8082 | 管理后台前端 |
| backend | 3000 | 后端API服务 |

## 题目内容

### 一、首页（数据总览 dashboard）
核心定位：全局数据可视化总览，快速掌握设备管理核心状态，无完整表格，以 "图表 + 卡片 + 进度条" 组合呈现。

核心功能：
- 核心指标卡片区：展示设备总数、在役设备数、待维护设备数、高风险设备数、本月新增采购数等关键指标
- 设备状态分布图表：环形图展示设备状态占比，点击可跳转对应管理页面
- 设备类型占比与使用科室分布：柱状图展示设备大类和科室分布
- 维护计划进度条：展示本月维护计划完成率、年度校准完成率
- 近期待办提醒：横向滚动卡片展示待办事项

### 二、设备台账管理页
核心定位：设备基础信息的核心管理入口，仅此处使用完整表格。

核心功能：
- 设备台账表格：筛选、搜索、分页、导出Excel、单行操作
- 台账健康度小图表：折线图和饼图
- 批量操作区：批量导入、批量修改、批量标记

### 三、采购管理页
核心定位：采购申请-审批-入库全流程管理，以"流程卡片+趋势图"呈现。

核心功能：
- 采购申请卡片流：按状态分类展示
- 采购趋势分析：柱状图和漏斗图
- 供应商关联卡片

### 四、维护管理页
核心定位：设备维护、校准、故障报修管理，以"进度图表+任务卡片"替代表格。

核心功能：
- 维护计划日历视图
- 维护完成率图表
- 故障报修看板

### 五、报废管理页
核心定位：设备报废申请-审核-处置管理，以"状态图表+流程卡片"呈现。

核心功能：
- 报废状态分布图表
- 报废申请流程卡片
- 报废数据统计

### 六、数据统计页
核心定位：多维度数据洞察，纯可视化图表组合，无表格。

核心功能：
- 全周期数据总览大屏
- 自定义统计分析

## 技术栈

- 前端：Vue 3 + Element Plus + ECharts + Vue Router
- 后端：Node.js + Express + SQLite
- 部署：Docker + Docker Compose

## 项目特点

- 医疗风格UI设计
- 响应式布局，全屏展示
- 图表与图例不重叠
- 所有组件支持滚动
- 完整的登录认证
- 不使用Pinia/Vuex状态管理
